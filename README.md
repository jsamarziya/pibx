# pibx

My Raspberry Pi PBX system.

## Hardware
- Raspberry Pi 4 Model B 2GB
- 64GB SD card

## OS
Raspberry Pi OS Lite 64-bit (trixie)\
Installed using Raspberry Pi Imager

## Setup
- `sudo dpkg-reconfigure locales`
- `sudo rm /etc/motd`
- `sudo apt update`
- `sudo apt full-upgrade`

## Packages
- git
- keychain
